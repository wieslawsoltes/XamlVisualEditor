# Security policy

## Supported versions

Security fixes are provided for the latest published release and the `main`
branch. Older releases may be asked to upgrade before a fix is supplied.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's
private **Report a vulnerability** flow on the repository Security tab. If that
flow is unavailable, contact the repository owner privately through the contact
details on the [maintainer's GitHub profile](https://github.com/wieslawsoltes).

Include the affected version, environment, reproduction steps, impact, and any
known mitigation. You should receive an acknowledgement within seven days.
Please allow time for investigation and a coordinated release before public
disclosure.
