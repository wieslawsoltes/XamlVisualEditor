# Documentation

This site documents XamlVisualEditor as an application, framework, and extension
platform. Start with the source build flow, then move into guides for editing,
designing, debugging, language services, collaboration, and extension authoring.

## Sections

- [Getting Started](getting-started/readme.md): prerequisites, source build, test
  commands, local docs build, and first workspace workflow.
- [Guides](guides/readme.md): feature tour, visual designer, editor, workspace,
  language services, debugging, terminal, collaboration, agents, and extension SDK.
- [Concepts](concepts/readme.md): shell architecture, XAML AST synchronization,
  extension hosting, and language/debugger service boundaries.
- [Reference](reference/readme.md): project map, CI/release workflows, internal
  documents, test matrix, and contribution rules.

## Audience

- App users evaluating the editing, designer, terminal, Git, debugger, and
  automation surfaces.
- Extension authors building native .NET packages for XamlVisualEditor.
- Contributors working on the Avalonia shell, XAML pipeline, Dock layout,
  language services, debugger tooling, terminal, or test infrastructure.
